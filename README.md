# Shopl 자산관리 프로토타입

`자산관리_구조설계안.md` / `자산관리_UX설계안.md` 기반의 클릭 가능한 화면 프로토타입.
정적 HTML/CSS/JS, 빌드 없음. GitHub Pages로 서비스.

## 현재 자산 모델 (2026-10-29 확정)

- 수량형을 제공하지 않으며, 자산 한 건은 사용자가 정한 관리 단위 하나입니다. 소모품도 한 개 또는 한 박스 등 원하는 단위로 등록합니다.
- 유형 선택 없이 구성원·근무지에 배정합니다. 같은 품목 여러 건은 일괄 추가로 등록하며, 회사 양식의 수량값으로 자산을 자동 분할하지 않습니다.
- 현황 통계는 자산 현황과 유효기한만 제공합니다. 사용을 마친 자산에는 기존 폐기를 사용합니다.

## 화면

| 파일 | 화면 | 상태 |
|---|---|---|
| `assets.html` | 현황 — 자산 목록 (진입 화면). 뷰 4종(전체/제품별/구성원별/근무지별), 툴바, 샘플 테이블 | 1차 |
| `asset-detail.html?id=` | 자산 상세. 기본정보 / 배정 현황 / 사진 / QR / 하위 액션 버튼 | 1차 |
| `category.html` | 분류 탭 | 스텁 |
| `settings.html` | 설정 탭 | 스텁 |
| `batch-register.html` | 일괄 자산 등록 | 스텁 |
| `batch-assign.html` | 일괄 배정 | 스텁 |

## 구조

- `js/shell.js` — 좌측 LNB + 상단바 공통 셸 (자산 메뉴만 활성)
- `js/data.js` — 샘플 데이터
- `js/assets.js` — 자산 목록 화면
- `js/detail.js` — 자산 상세 화면
- `css/app.css` — 전체 스타일

## 로컬 실행

```
python3 -m http.server 8080
# http://localhost:8080
```
